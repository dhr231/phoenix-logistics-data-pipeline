# Phoenix Logistics Data Pipeline

## Overview

A hands-on Data Engineering project built around real-world logistics
booking and billing data.

## Objective

Build a reliable pipeline to:

- Load operational data
- Normalize inconsistent fields
- Validate data quality
- Reconcile Booking and Billing datasets
- Identify missing and duplicate records
- Safely join datasets
- Generate business-level insights

## Tech Stack

- Python
- Pandas
- SQL
- SQLite
- Git/GitHub
